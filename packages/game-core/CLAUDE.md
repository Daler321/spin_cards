# packages/game-core

Чистая логика игры и симулятор. Никакого I/O: ни БД, ни сети, ни `Date.now()`, ни `Math.random`.
Всё снаружи через интерфейсы из `src/ports.ts` (`rng`, `clock`, `uniquenessChecker`). Ничего не
импортировать из `apps/*`.

## Структура

- `src/spin.ts` — один прокрут: тир, номер, узоры, множитель, near-miss.
- `src/number/` — `generate.ts` (номер: первая 9, не проходит Луна, `luhn.ts`), `patterns.ts`
  (узоры, лестницы, блоки, полный дубль D-148), `digits.ts`.
- `src/luck/` — удача и веса тиров (D-147), буст, состояние новичка; `src/near-miss.ts`.
- `src/valuation.ts` — баланс карты, потолок множителя; `src/progress.ts` — уровни и опыт.
- `src/quests.ts`, `src/achievements.ts` — правила заданий и медалей; `src/math.ts`.
- `src/sim/simulate.ts`, `src/sim/stats.ts` — симулятор RTP (используется проверкой конфига в api
  и `make sim`); `src/seeded-rng.ts` — детерминированный rng для тестов.

## Команды

- `make check P=packages/game-core` — eslint + prettier + typecheck + vitest (dot).
- После правки: `make typecheck` всего репо (api и web импортируют пакет).
- `make sim ARGS="--pack basic --spins 1000000 --json"` — RTP; `make progression`.

## Правила тестов

- Покрытие ≥ 90 %, тесты с seed (`test/helpers.ts`). Обязательные темы: паттерны (лестницы 5–10,
  пересечения блоков), потолок множителя, near-miss, pity, шкала удачи, новичок, потолок бонусов,
  уникальность и пул.
- Снимки в `test/__snapshots__/` обновлять только осознанно.

## Частые ошибки

- Near-miss только подсказка по выпавшему; не смещать генератор.
- `9777 7777 7777 7777` проходит Луна и не выдаётся (D-148); проверять Луна для новых «красивых» номеров.
- Минёр (D-169): бонус «SpinCards» встроен в лестницу (без бонуса шаг /(пустых + b)); простой ×(1 + b) к выплате даёт возврат до 117 %.
- Изменение весов или множителей меняет RTP: прогнать симулятор, коридор 85–110 % (regular и bestCard).
